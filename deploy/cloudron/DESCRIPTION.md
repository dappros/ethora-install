Ethora is a chat and messaging platform you run yourself: a web chat and
admin panel, an API, an XMPP server (ejabberd) and file storage, with mobile
and web SDKs on top. Create apps, users and chat rooms, and connect your own
clients through the API and the SDKs.

### Features

* Web chat and admin panel for apps, users, rooms and settings
* REST API (documented at `/api-docs/`) and real-time messaging over XMPP
* File sharing, stored in the app's own MinIO
* Multi-tenant: one server hosts many apps, each with its own users
* Web chat component and backend SDKs, and an MCP server for AI tools
