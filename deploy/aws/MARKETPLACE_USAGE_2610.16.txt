1. Launch with a key pair and the recommended security group (80 and 443 open to all; 22 and 8888 only from your address). t3.medium or larger, 40 GB volume. An Elastic IP is recommended.
2. Create DNS A records for api., app., xmpp., files. and secure-files. under your domain, pointing at the instance (one wildcard record covers them; subdomains work, for example app.chat.company.com). Without DNS records, use the magic name <ip-with-dashes>.sslip.io as the domain, for example 203-0-113-10.sslip.io; it resolves to the instance on its own.
3. Open the setup page on port 8888 of the instance's public IP (plain HTTP). User: admin. Password: the instance id (i-...). Enter the domain, your e-mail and, optionally, an Enterprise license key. Submit once; the page shows the install log, runs an end-to-end check, then shows the admin URL and the generated admin password.
4. After about three minutes open the app. host of your domain over HTTPS and sign in. The setup page switches itself off. The install is a Docker Compose project in /home/ubuntu/ethora-install-shared/deploy/compose: settings in its .env file (then docker compose up -d --force-recreate), updates with git pull and docker compose pull and docker compose up -d, data in the Docker volumes ethora_mongo, ethora_mysql, ethora_minio, ethora_redis, ethora_caddy-data and ethora_secrets (backup steps in that directory's README).
Unattended installs: the CloudFormation template in the documentation repository passes the same answers through instance user data.
Documentation: https://github.com/dappros/ethora-install
