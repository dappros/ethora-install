# Platform templates for the compose bundle

- `portainer-template.json`: a Portainer app template (format v3) that
  deploys `deploy/compose/docker-compose.yml` from the public installer
  repository. Add its raw URL under Settings > App Templates in Portainer,
  or submit it to the Portainer community templates. Secret fields left
  empty are generated on the first start (kept in the `secrets` volume).
- `coolify/`: how to run the bundle on Coolify as a Docker Compose
  application from the public installer repository (the supported way,
  verified end to end), and `ethora-core.yaml`, a draft one-click service
  template generated from `coolify/ethora-core.in.yaml` by
  `coolify/build-template.sh` with the bundle's scripts and templates
  inline. See `coolify/README.md`.
- `dokploy/`: how to run the bundle on Dokploy as a Compose service from
  the public installer repository (the supported way, verified end to end),
  and a blueprint in the format of `github.com/Dokploy/templates`
  (`docker-compose.yml`, `template.toml`, `meta.json`, `ethora.svg`),
  generated from the bundle by `dokploy/build-template.sh` with the scripts
  and templates as file mounts and every secret generated by Dokploy;
  deployed and verified from a served catalogue, not yet submitted. See
  `dokploy/README.md`.
- `umbrel/`: the umbrelOS app package, `umbrel/ethora/` (copy it into
  `getumbrel/umbrel-apps` as-is), generated from the single file
  (`../single/docker-compose.yml`) by `umbrel/build.sh`: Umbrel's
  `app_proxy` in front of the bundled Caddy on one origin, data under
  `${APP_DATA_DIR}/data`, secrets derived per install in `exports.sh`.
  Verification status and the submission steps are in `umbrel/README.md`.
- `casaos/`: the CasaOS / ZimaOS app, `casaos/docker-compose.yml` with its
  `x-casaos` block, generated from the single file by `casaos/build.sh`.
  Verification status and the submission steps are in `casaos/README.md`.
- `images.env`: the exact image of every service for the store packages
  (tag and multi-arch digest, as Umbrel requires), written by
  `pin-images.sh <release build>`. After a release build, run it and then
  both `build.sh` scripts.
