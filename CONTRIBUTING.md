# Contributing

This repository is published automatically from Dappros's integration
repository, so pull requests here cannot be merged directly. What helps:

- **Bug reports and installer problems:** open an issue with the output of
  `deploy/scripts/health-check.sh` and the install or update log (never
  `deploy.yml` or `.deploy.env`). Say which OS, release line and cloud.
- **Documentation fixes:** open an issue or a pull request against this
  repository; we carry accepted changes into the source and they appear
  here on the next sync.
- **The open-source parts of Ethora** (web client, chat component, SDKs, MCP
  server) accept pull requests in their own repositories under
  https://github.com/dappros.

Code of conduct: be respectful, assume good faith, keep it about the work.
